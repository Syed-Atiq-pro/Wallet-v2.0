# 💰 WalletX — Personal Finance Manager

**Manage your money. Track expenses. Make informed decisions. All in one app.**

---

## 📋 Problem Statement

Managing money is confusing. Most finance apps are:
- Too complicated (too many features you don't need)
- Require login/subscription (privacy concerns, cost)
- Don't show real-time insights (confusing dashboards)
- No multi-currency support (bad for global users)

**WalletX** fixes this: Simple, powerful, free personal finance management with real-time currency conversion.

---

## ✨ Key Features

- 💵 **Track Income & Expenses** — Log every transaction with category
- 📊 **Real-Time Dashboard** — See your balance at a glance
- 🌍 **Multi-Currency Support** — Convert between 26+ currencies instantly
- 📈 **Spending Trends** — Visualize where your money goes
- 🏷️ **Smart Categories** — Pre-built categories (food, transport, entertainment, etc.)
- 💾 **Persistent Storage** — Your data saved locally
- 📱 **Mobile First** — Perfect on any device
- 🔓 **100% Private** — No server tracking, no ads

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Charts:** Chart.js (free, open-source)
- **API:** ExchangeRate-API (free tier for currency conversion)
- **Storage:** Browser LocalStorage
- **Deployment:** GitHub Pages
