💰 WalletX — Personal Finance Manager

A full-featured personal finance tracker with multi-currency 
support and spending trend visualization.

## 🚀 Live Demo
👉 [Open App](https://Syed-atiq-pro.github.io/Wallet-v2.0)

## ✨ Features
- 💸 Log daily income and expense transactions
- 📊 Live budget summary and balance tracking
- 🌍 Real-time multi-currency converter
- 📈 Spending trend visualization
- 🧠 Smart saving insights through clean dashboards
- 📱 Fully responsive design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (ES6+)
- Deployed via GitHub Pages

## 💡 Why I Built This
Managing money is hard. WalletX makes it simple — 
track what comes in, what goes out, and where to save.
